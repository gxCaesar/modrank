# S5 development results

Every JSON the exploratory campaign produced, moved here from a session scratchpad on 2026-08-18.

**Why this directory exists.** The manuscript cites numbers from this campaign — the capacity
sweep, the weight sweep, the seven falsified components, the multi-encoder comparison — and until
now every one of them lived only in a temporary directory that is deleted when the session ends.
The figures load from these files, so a scratchpad that vanished would have taken the ability to
rebuild the figures with it.

**Status: exploratory, `phase_of_origin: exploratory`.** These are pre-freeze. Nothing here is a
reportable number on its own; the frozen confirmatory run and its post-hoc analyses are in
`experiments/20260817-blca-confirm/results/`. What these files support is the *design* argument —
why the method has the shape it has — which is exactly the use S02 permits for exploratory-phase
evidence.

`regime-evidence.json` in the confirmatory results directory is the curated extract of the two
tables the manuscript actually quotes from `baseline-ledger.md`; these files are the raw form it
was extracted from.
