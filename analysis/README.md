# Analysis code

Every number reported in the manuscript is produced by a script in this directory. Forty files,
8,160 lines, moved here from a session scratchpad on 2026-08-18 — before that they lived only in a
temporary directory that is deleted when the session ends, which meant the paper's evidence could
not have been regenerated by anyone, including us.

**No script here embeds a scientific decision.** Thresholds, column names, the alpha grid, the
combination rule and the decision rule live in the frozen protocol; these scripts consume it. The
separation is what makes a threshold auditable: embedded in a script it could be changed without
leaving a trace in the protocol, and nobody reading the protocol afterwards would know.

## Order

The dependency order is the file prefix. `blca_common.py` defines the cohort, the folds, the labels
and the estimator once, so no two arms can silently use different ones — that single definition is
the reason the paired comparisons are paired.

| stage | what it establishes |
|---|---|
| `blca_common.py`, `bio_stats.py` | the cohort, the estimator, and the statistics, each with a known-answer selftest that runs at import |
| `s5_step0`, `s5_step1` | headroom above the cheap baselines, and the error per slice — run **before** anything was designed |
| `s5_c1` … `s5_c7` | the seven components, each with its matched control |
| `s5_fusion_probe`, `s5_oracle_correction` | whether the combination rule is the deficit (it is not), and the correction to the oracle control |
| `s5_method`, `s5_final`, `s5_headline` | the arm, with every selection moved inside the training fold |
| `s6_leakage_falsifiers` | five falsifiers, run **before** the protocol freeze; two rejected |
| `s6_confirmatory` | the confirmatory run, executed once against the frozen protocol |
| `s6_amend_clinical` | amendment A1 — the clinical block rebuilt from the incumbent's own released files |
| `s7_*` | the post-freeze analyses: survival metrics, ablation, generalisation, calibration, case series, seed-matching, and the reviewer gaps |
| `s8_biology` | the biological association analysis, with both case-selection rules fixed in the docstring before the run |
| `s9_pibd_parity` | PIBD scored by our code and given the same clinical block |
| `s10_figure_data` | the four quantities the figures need as curves rather than summaries |
| `s11_cold_panel_round1` | the two measurements cold panel round 1 earned: the inductive-normalisation rerun and the stage-vs-grade interval |

`extract_fm.py`, `pool_chief.py`, `inspect_pkl.py`, `verify_pkl.py` and `patch_core.py` ran on the
compute host: feature extraction, per-slide pooling, and the checks that established a competitor's
released pickles could be recomputed before any paired test was run against them. Their default
paths are the ones they ran at; each takes an environment override.

## Two conventions worth knowing before reading any of it

**A control is read before its result.** Several scripts assert that a control still behaves — that
a permuted-stratum control still beats the gated component, that the seven-encoder ensemble is still
significantly worse than TITAN alone. Those asserts fail the run rather than producing a figure that
quietly no longer shows what its caption says.

**A statistic that produces a reported number has a known-answer test.** `bio_stats.selftest()` runs
at import and checks Benjamini–Hochberg against the 1995 worked example, the Spearman null rate, and
the Cox score test's sign against its mirror. That last one was added because the sign assertion was
originally written backwards.

## Running it

Python 3.9+, numpy, scipy, matplotlib. The inputs are the released SurvPath split files, the public
precomputed TITAN embeddings, and DIMAF's released split files; none is redistributed here. Each
script takes its input directories as arguments and writes one JSON to `--out`.
